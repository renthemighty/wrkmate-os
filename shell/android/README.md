# Android Shell

This directory will hold the Android launcher replacement: on a device with an unlocked bootloader, this becomes the primary interface in place of the stock launcher, wiring the resolver and the activation engine into always-ready voice input, contact and calendar access, and a confirmation interface. Nothing is built here yet; this is a phase 3 item on the roadmap. See `docs/roadmap.md` and `docs/architecture.md` for context.
