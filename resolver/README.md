# Resolver

This directory will hold the on-device streaming resolver: the component that listens to speech as it arrives, matches it against the keyword and entity library described in `spec/keyword-library.md`, and emits intent frames matching `spec/intent-frame.md`.

Nothing is built here yet. This is a phase 1 item on the roadmap. See `docs/roadmap.md` for where this fits and `docs/architecture.md` for how it connects to the shell and the activation engine.
